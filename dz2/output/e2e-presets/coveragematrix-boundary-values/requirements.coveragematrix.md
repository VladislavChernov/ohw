# Матрица покрытия: requirements.md

**Тестируемый сайт:** https://otus.ru/catalog/courses?categories=programming

## Матрица покрытия требований

| Requirement ID | Requirement Description | Test Case IDs | Coverage Status | Notes |
|---|---|---|---|---|
| BR-1 | При открытии ссылки каталог показывает только курсы направления «Программирование»; посторонних курсов в выдаче нет | TC-01 | Covered | — |
| BR-2 | Карточка курса до перехода внутрь даёт достаточно информации для решения: название, длительность или дата старта, стоимость (или признак «бесплатно» / «старт скоро»), кнопка или ссылка действия («Записаться», «Подробнее») | TC-02, TC-03, TC-04 | Covered | — |
| BR-3 | Клик по карточке открывает страницу этого курса; переход не заканчивается ошибкой или 404 | TC-05 | Covered | — |
| BR-4 | Фильтры на странице реально меняют список курсов; сброс фильтров возвращает исходную выдачу | TC-06 | Covered | — |
| BR-5 | Выбранное состояние фильтра видно в адресной строке (`?categories=...`); ссылку можно открыть заново и увидеть тот же отфильтрованный список | — | Not Covered | — |
| BR-6 | Пагинация работает: переключатель страниц присутствует, переход на следующую страницу меняет состав выдачи (курсы не дублируют предыдущую страницу), возврат на предыдущую страницу работает, номер страницы виден в адресной строке (`&page=2`) | — | Not Covered | — |
| BR-7 | Некорректные параметры адресной строки не ломают страницу: несуществующая категория или номер страницы за пределами списка дают пустую выдачу либо корректное сообщение, а не ошибку сервера | TC-07, TC-08, TC-09, TC-10 | Covered | — |
