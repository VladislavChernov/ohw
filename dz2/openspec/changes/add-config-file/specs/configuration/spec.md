# Delta Spec: configuration

## ADDED Requirements

### Requirement: Конфигурационный файл

Программа ДОЛЖНА читать файл конфигурации в формате TOML: секции `[ollama]`
(base_url, model, timeout), `[paths]` (input_dir, output_dir), `[generation]`
(temperature, max_retries). Если аргумент `--config` не указан, программа
ДОЛЖНА искать файл `ai-testgen.toml` в текущем каталоге; отсутствие файла
не является ошибкой — применяются значения по умолчанию.

#### Scenario: Параметры из конфига применяются

- **WHEN** в `ai-testgen.toml` заданы model и output_dir, CLI их не переопределяет
- **THEN** программа использует модель и каталог из конфига

#### Scenario: Конфигурационный файл отсутствует

- **WHEN** `--config` не указан и `ai-testgen.toml` не найден
- **THEN** программа работает со значениями по умолчанию

#### Scenario: Явный путь до несуществующего файла

- **WHEN** указан `--config missing.toml`, файла нет
- **THEN** программа завершается с кодом 2

### Requirement: Приоритет слоёв конфигурации

Значение каждого параметра ДОЛЖНО выбираться по приоритету:
значение по умолчанию < конфигурационный файл < переменные окружения
`OLLAMA_BASE_URL`/`OLLAMA_MODEL` < аргументы CLI. Диапазонные проверки
выполняются после резолвинга итогового значения.

#### Scenario: CLI переопределяет конфиг

- **WHEN** temperature задан и в конфиге (0.7), и через `--temperature 0.2`
- **THEN** используется 0.2

#### Scenario: Env переопределяет конфиг

- **WHEN** model задана в конфиге, а также переменной `OLLAMA_MODEL`
- **THEN** используется значение из переменной окружения

### Requirement: Модель обязательна хотя бы в одном источнике

Имя модели ДОЛЖНО быть задано хотя бы в одном источнике (конфиг или
переменная окружения). Если нигде не задано, программа завершается с кодом 2.

#### Scenario: Модель только в конфиге

- **WHEN** env `OLLAMA_MODEL` не задана, в конфиге модель указана
- **THEN** программа работает без ошибок конфигурации модели

#### Scenario: Модель не задана нигде

- **WHEN** ни env, ни конфиг не содержат имя модели
- **THEN** программа завершается с кодом 2 до обращения к ollama
