# Proposal: конфигурационный файл ai-testgen.toml

## Зачем

Сейчас адрес ollama и имя модели задаются переменными окружения в каждой
сессии, а `docker run` требует `-e` флагов. Инфраструктурные настройки
(`base_url`, `model`), пути и «тюнинг»-параметры генерации меняются редко —
им место в файле конфигурации, а не в командной строке.

## Что делаем

- Файл `ai-testgen.toml` с секциями `[ollama]`, `[paths]`, `[generation]`.
- Чтение через stdlib `tomllib` (Python 3.13) — без новых зависимостей.
- Аргумент CLI `--config <path>`; по умолчанию автопоиск `ai-testgen.toml`
  в текущем каталоге, отсутствие файла ошибкой не является.
- Слои приоритета: `defaults < ai-testgen.toml < env (OLLAMA_*) < CLI`.
- `OLLAMA_MODEL` перестаёт быть безусловно обязательным: достаточно задать
  модель в конфиге или env; exit 2 только если нигде не найдена.

## Не выносим в конфиг

- `--count` — намерение конкретного запуска.
- `--url` — данные входного файла.

## Impact

- `cli.py`: резолвинг значений из четырёх слоёв; новые сообщения об ошибках.
- Новый модуль `config.py`; README; тесты precedence.
