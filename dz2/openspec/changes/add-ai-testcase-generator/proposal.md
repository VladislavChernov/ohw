# Proposal: AI-генератор тест-кейсов для веб-сайтов

## Зачем

Нужна утилита, которая с помощью локальной LLM (ollama на NVIDIA 2070 SUPER)
автоматически генерирует тест-кейсы для тестирования веб-сайта по
markdown-описанию требований. Это учебный проект (Otus, ДЗ2): цель — освоить
связку Python + uv + Docker + Dev Container + локальный LLM-инференс.

## Что делаем

CLI-программа на Python:

1. Читает файлы требований из входной папки (`--input-dir`, по умолчанию
   `./input`): каждый файл — markdown или обычный текстовый (.md/.txt) с
   промптом, требованиями к тестированию и адресом тестируемого сайта.
2. Подключается к уже запущенному ollama-контейнеру (GPU NVIDIA RTX 2070 SUPER).
3. Отправляет по каждому файлу запрос на генерацию N тест-кейсов (N — аргумент
   CLI, применяется к каждому файлу).
4. Валидирует ответ модели: ровно N кейсов, есть и позитивные, и негативные.
5. Записывает результат по каждому файлу в выходную папку (`--output-dir`,
   по умолчанию `./output`): `<имя входного файла>.md`.

Программа сама упаковывается в docker-контейнер; для разработки — VS Code
Dev Container.

## Ограничения

- ollama-контейнер **уже существует** у пользователя (модель предустановлена) —
  не создаём его заново, только подключаемся. Имя/порт/модель — через
  переменные окружения.
- GPU доступен через Docker Desktop (WSL2 backend) + NVIDIA driver.
- Модель на 8 GB VRAM (2070 SUPER): параметры генерации должны укладываться
  в контекст; большие запросы не дробим без необходимости.

## Изменения

- Новый проект `ai-testcase-generator`:
  - Python-пакет с CLI (`argparse`), менеджер зависимостей — `uv`;
  - модуль интеграции с Ollama HTTP API;
  - валидатор структуры ответа LLM;
  - рендер markdown-отчёта;
  - `Dockerfile` + `compose`-сервис приложения (подключается к существующей
    сети ollama);
  - `.devcontainer` для VS Code;
  - тесты (pytest): unit на валидатор/рендер, integration — помечены маркером
    и требуют живого ollama.

## Impact

- Код: новый проект, обратной совместимости нет.
- Инфраструктура: используется существующий контейнер ollama; новых
  долгоживущих сервисов не добавляем.
