# Задачи: настройки нормализатора отдельным файлом и в UI

## Конфигурация

- [x] `dz2/normalizer.toml`: отдельный плоский TOML с шестью ключами и
  комментариями; не секция `ai-testgen.toml`.
- [x] `NormalizerSettings` в `normalizer.py` с валидацией в `__post_init__` и
  отдельной ошибкой `NormalizerSettingsError`.
- [x] `load_settings(path)`: порядок `--normalizer-config` →
  `AI_TESTGEN_NORMALIZER_CONFIG` → `./normalizer.toml` → встроенные значения;
  неизвестные ключи — предупреждение, а не падение.
- [x] Встроенные значения совпадают с прежним хардкодом.

## Ядро

- [x] `decode_bytes(data, settings)`: кодеки из `encodings`, UTF-8 и BOM всегда
  первыми, при равном счёте побеждает первый в списке.
- [x] `normalize_text(..., settings)`: префикс, заголовок раздела, подпись URL,
  запасной заголовок и порог абзаца из настроек.
- [x] Регулярные выражения строятся из префикса; `BR-N` распознаётся всегда,
  чтобы смена префикса не теряла существующие ID.
- [x] `load_docs(..., settings)` прокидывает настройки в декодирование и
  нормализацию.

## CLI

- [x] `--normalizer-config PATH`.
- [x] Отсутствующий или битый файл настроек — код 2 с сообщением.
- [x] Автопоиск `normalizer.toml` в рабочей директории.

## Рабочее место

- [x] Блок «Настройки нормализации»: шесть виджетов, значения по умолчанию из
  файла, кнопка «Вернуть значения из файла».
- [x] Правки живут в сессии и не пишутся в файл.
- [x] Смена настроек после нормализации помечает результат устаревшим.

## Docker

- [x] `normalizer.toml` копируется в образ и монтируется в `app` и `ui`.
- [x] Образ задаёт `AI_TESTGEN_NORMALIZER_CONFIG=/app/normalizer.toml`: рабочий
  каталог контейнера — `/data`, поэтому поиск по `./normalizer.toml` сам по себе
  файл бы не нашёл.

## Документация

- [x] `dz2/NORMALIZER-SETTINGS.md`: глоссарий по каждому параметру, порядок
  поиска, влияние на промпт, типовые ошибки, рецепты, ограничения.
- [x] Ссылки из `dz2/README.md` и `dz7/docs/NORMALIZER.md`.

## Тесты

- [x] `tests/test_normalizer.py`: файл меняет префикс/заголовки/подписи,
  идемпотентность с нестандартными настройками, порог абзаца, кодеки,
  валидация, предупреждение о неизвестных ключах.
- [x] `tests/test_cli_normalize.py`: флаг, автопоиск, коды возврата.
- [x] `tests/test_ui_app.py`: виджет префикса меняет ID в промпте, файл задаёт
  значения по умолчанию.
- [x] Полный прогон в Docker: pytest, mypy, ruff.
