# Требования к тестированию: страница авторизации

Тестируемый сайт: https://www.saucedemo.com

Проверить страницу авторизации:

- вход с валидными учётными данными стандартного пользователя;
- блокировка доступа при неверном пароле;
- поведение при пустых полях логина и пароля;
- сообщение об ошибке должно быть читаемым и не раскрывать лишнюю информацию;
- после успешного входа пользователь попадает на страницу каталога товаров.
