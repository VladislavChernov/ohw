# Тест-кейсы: cart.txt

**Тестируемый сайт:** https://www.saucedemo.com

**Всего кейсов:** 5 (позитивных: 3, негативных: 2)

## Позитивные сценарии

### TC-01. Успешная регистрация нового пользователя

**Тип:** позитивный

**Проверяет требование:** BR-1

**Предусловия:**

- Пользователь не зарегистрирован на сайте

**Шаги:**

| № | Действие |
|---|----------|
| 1 | Перейти на страницу регистрации |
| 2 | Заполнить форму регистрации с корректными данными |
| 3 | Нажать кнопку "Зарегистрироваться" |

**Ожидаемый результат:** Появляется сообщение об успешной регистрации и пользователь перенаправляется на страницу входа

### TC-02. Успешная авторизация существующего пользователя

**Тип:** позитивный

**Шаги:**

| № | Действие |
|---|----------|
| 1 | Перейти на страницу входа |
| 2 | Заполнить форму входа с корректными данными |
| 3 | Нажать кнопку "Войти" |

**Ожидаемый результат:** Пользователь успешно авторизован и перенаправлен на главную страницу

### TC-04. Успешное изменение пароля

**Тип:** позитивный

**Проверяет требование:** BR-3

**Предусловия:**

- Пользователь уже авторизован на сайте

**Шаги:**

| № | Действие |
|---|----------|
| 1 | Перейти на страницу изменения пароля |
| 2 | Заполнить форму с текущим паролем и новым паролем |
| 3 | Нажать кнопку "Сохранить" |

**Ожидаемый результат:** Пароль успешно изменен, пользователю предлагается перейти на страницу входа с новым паролем
