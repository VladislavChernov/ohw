# Тест-кейсы: auth.md

**Тестируемый сайт:** https://www.saucedemo.com

**Всего кейсов:** 5 (позитивных: 1, негативных: 4)

## Позитивные сценарии

### TC-01. Вход с валидными учётными данными стандартного пользователя

**Тип:** позитивный

**Проверяет требование:** BR-1

**Шаги:**

| № | Действие |
|---|----------|
| 1 | Открыть страницу авторизации https://www.saucedemo.com |
| 2 | Ввести валидное имя пользователя 'standard_user' |
| 3 | Ввести валидный пароль 'secret_sauce' |
| 4 | Нажать кнопку 'Login' |

**Ожидаемый результат:** Пользователь попадает на страницу каталога товаров
