# Чек-лист: checklist_md.md

**Тестируемый сайт:** https://otus.ru/catalog/courses?categories=programming

## Ограничение

- Ничего не выдумывать — использовать только стандартные проверки
веб-страницы и проверки по бизнес-требованиям.

## Правило трассировки

- Каждый пункт чек-листа завершить номером проверяемого требования
в скобках, например «(BR-1)».

## Бизнес-требования (проверяются посетителем с первого захода)

- **BR-1** — каталог содержит только курсы направления «Программирование».
- **BR-2** — карточка курса показывает название, длительность или дату
   старта, стоимость и кнопку действия.
- **BR-3** — клик по карточке открывает страницу курса без ошибки.
- **BR-4** — фильтры меняют список курсов, сброс возвращает исходную выдачу.
- **BR-5** — выбранный фильтр виден в адресной строке.
- **BR-6** — пагинация переключает страницы, курсы не дублируются между
   страницами, номер страницы виден в адресной строке.
- **BR-7** — некорректные параметры адресной строки не ломают страницу.

## Зоны чек-листа

- **Заголовок страницы и мета-информация (BR-1, BR-7)**
  - Заголовок страницы содержит текст «Программирование».
  - В мета-описании страницы присутствует ключевое слово «Программирование».
- **Карточки курсов (BR-2, BR-3)**
  - Каждая карточка содержит название курса.
  - Каждая карточка содержит длительность или дату старта.
  - Каждая карточка содержит стоимость курса.
  - Каждая карточка содержит кнопку действия.
  - Клик по карточке перенаправляет на страницу курса.
- **Фильтры и их отражение в адресной строке (BR-4, BR-5)**
  - В нижнем меню присутствуют фильтры.
  - При выборе фильтра список курсов изменяется.
  - После применения фильтра в адресной строке отображается выбранный фильтр.
  - При сбросе фильтра возвращается исходный список курсов.
  - В адресной строке отсутствует фильтр при отсутствии фильтрации.
- **Пагинация (BR-6)**
  - При переходе между страницами перечень курсов изменяется.
  - Курсы не повторяются между страницами.
  - Номер текущей страницы отображается в адресной строке.
- **Некорректные параметры в адресной строке (BR-7)**
  - При вводе несуществующего параметра в адресной строке страница не ломается.
