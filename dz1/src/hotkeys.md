# Горячие клавиши: VS Code vs IntelliJ IDEA (Python)

| Действие | IntelliJ IDEA | VS Code (Windows) | VS Code (macOS) | Комментарий |
| --- | --- | --- | --- | --- |
| Переименовать символ (refactor rename) | Shift+F6 | F2 | F2 | Работает для переменных, функций, классов |
| Быстрое исправление (quick fix) | Alt+Enter | Ctrl+. | Cmd+. | Подсказки по исправлению ошибок и импортов |
| Форматировать код | Ctrl+Alt+L | Shift+Alt+F | Shift+Option+F | Нужен установленный форматер (Black/Ruff) |
| Закомментировать строку | Ctrl+/ | Ctrl+/ | Cmd+/ | Идентично |
| Закомментировать блок | Ctrl+Shift+/ | Shift+Alt+A | Shift+Option+A |  |
| Перейти к определению | Ctrl+B или клик с Ctrl | F12 или клик с Ctrl | F12 или клик с Cmd |  |
| Перейти к символу в файле | Ctrl+Shift+Alt+N | Ctrl+Shift+O | Cmd+Shift+O | Вводишь имя функции/класса — получаешь список |
| Найти везде (по проекту) | Double Shift | Ctrl+T (символы) или Ctrl+P (файлы) | Cmd+T / Cmd+P | Ctrl+P — быстрый поиск файла |
| Множественные курсоры | Alt+Click | Alt+Click | Option+Click | Полностью идентично |
| Дублировать слово/выделение | Ctrl+D | Ctrl+D | Cmd+D | Выделяет следующее вхождение, можно править все сразу |
| Выделить все вхождения слова | Ctrl+F3 | Ctrl+F2 | Cmd+F2 |  |
| Перейти к строке по номеру | Ctrl+G | Ctrl+G | Cmd+G |  |
| Открыть терминал | Alt+F12 | Ctrl+` | Cmd+` | ` — обратный апостроф (слева от 1) |
| Палитра команд (аналог Find Action) | Ctrl+Shift+A | Ctrl+Shift+P | Cmd+Shift+P | Самая полезная команда: можно найти и запустить любое действие |
