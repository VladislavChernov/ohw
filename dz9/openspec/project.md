# Project: model-quality-lab

Учебный проект (Otus, ДЗ9): загрузка датасета, обучение модели, предсказания,
вычисление метрик качества, автотесты и визуализация метрик.

## Стек

- Python 3.13, пакетный менеджер **uv**, lock-файл коммитится.
- ML: **scikit-learn**, **matplotlib**; массивы — numpy (через зависимости).
- Тесты: **pytest**, `ruff`, `mypy`.

## Конвенции

- Спеки в формате OpenSpec: `openspec/changes/<change>/{proposal,design,tasks}.md`
  + дельты в `specs/<capability>/spec.md`.
- Требования — EARS: `SHALL` + сценарии `WHEN/THEN`.
- Код и комментарии — на английском; документация (README, TZ, спеки) — на
  русском.
- ML-контейнеров нет: библиотека Python + pytest; новые зависимости —
  только с обоснованием.

## Окружение

- Датасет: CSV в `dz9/data/` (путь переопределяется конфигом/аргументами).
- Модель: по умолчанию scikit-learn (скользящий перцептрон / логистическая
  регрессия), фиксированный `random_state`.
- Выход: `dz9/output/` — модель, график метрик.

## Границы

- Новый код — только в `dz9/`.
- Никаких новых контейнеров, сервисов, портов.
- Никакого LLM-контура: задача чисто классический ML-конвейер.
