# Дельта спеки: model-quality-lab

## ADDED Requirements

### Requirement: Загрузка датасета и разбиение

- Система SHALL загружать датасет через registry (`breast_cancer`,
  `pima_indians`, `heart`) или CSV с колонками признаков и бинарной меткой
  `label ∈ {0, 1}`.
- Система SHALL разделять данные на обучающий и тестовый наборы.
- Система SHALL использовать стратификацию по целевой переменной при
  бинарной метке.
- Система SHALL фиксировать seed для воспроизводимости разбиения.

#### Scenario: Корректное разбиение

- **WHEN** датасет загружен
- **THEN** обучающая и тестовая выборки покрывают исходный датасет без
  пересечения
- **AND** дисбаланс классов сохранён через стратификацию.

#### Scenario: Некорректный датасет

- **WHEN** датасет не содержит метку `label` или метка вне `{0, 1}`
- **THEN** загрузка завершается ошибкой.

### Requirement: Несколько датасетов

- Система SHALL поддерживать несколько датасетов через registry:
  `breast_cancer`, `pima_indians` и `heart` (демо).
- Система SHALL выполнять конвейер для датасета, выбранного ключом
  конфигурации (`--dataset`), и отдельно — для всех примеров
  (`--all-datasets`).

### Requirement: Обучение модели

- Система SHALL реализовывать модель классификации на Python 3.
- Система SHALL обучать модель на обучающих данных.
- Система SHALL сохранять обученную модель.

### Requirement: Предсказания и метрики

- Система SHALL выполнять предсказания на тестовых данных.
- Система SHALL вычислять accuracy, precision и recall по матрице ошибок.

- **WHEN** метрики вычисляются
- **THEN** `accuracy = (TP + TN) / N`
- **AND** `precision = TP / (TP + FP)`
- **AND** `recall = TP / (TP + FN)`.

#### Scenario: Метрики на микроданных

- **WHEN** истинная метка `y_true = [1, 0, 1, 1]`, предсказание
  `y_pred = [1, 0, 0, 1]`
- **THEN** `TP = 2`, `TN = 1`, `FP = 0`, `FN = 1`
- **AND** `accuracy = 0.75`, `precision = 1.0`, `recall = 0.67`.

#### Scenario: Нулевой знаменатель

- **WHEN** `TP + FP = 0`
- **THEN** `precision = 0.0`.

#### Scenario: Нулевой знаменатель при recall

- **WHEN** `TP + FN = 0`
- **THEN** `recall = 0.0`.

### Requirement: Автотесты

- Система SHALL выполнять автотесты, проверяющие загрузку данных, обучение,
  метрики и сохранение модели.

### Requirement: Визуализация

- Система SHALL создавать визуализацию метрик и сохранять её в файл.
- Система SHALL строить сравнительный график метрик по нескольким
  моделям/датасетам (`plot_comparison`).

### Requirement: Несколько моделей

- Система SHALL поддерживать модели `logistic_regression` и `perceptron`
  (MLP не входит в объём работ).
- Система SHALL выполнять конвейер для одной модели (`--model`) или всех
  (`--all-models`) и строить сравнительный график при нескольких прогонах.
