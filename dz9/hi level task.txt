Задача:


Реализовать систему, которая выполняет следующие функции:


загружает датасет;

обучает модель;

генерирует автотесты для проверки качества модели;

вычисляет метрики качества обученной модели.


Вам нужно:


Загрузить датасет и разделить его на два набора: обучающий и тестовый.

Реализовать модель на Python 3 и обучить её.

Провести предсказания на тестовом наборе из подготовленного датасета.

Вычислить для модели следующие метрики:

долю верно предсказанных случаев;

долю верно предсказанных положительных случаев среди всех предсказанных положительных;

долю верно предсказанных положительных случаев среди всех реальных положительных.


Написать автотесты, которые проверят следующее:

корректность загрузки данных;

корректность обучения модели;

корректность вычисления метрик;

сохранение модели.


Создать визуализацию полученных данных для метрик, используя любую библиотеку для Python 3.
