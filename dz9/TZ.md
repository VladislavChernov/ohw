## 1. Цель

Создать в `dz9` систему проверки качества обученной модели end-to-end:

1. загружать датасет;
2. реализовывать модель на Python 3 и обучать её;
3. проводить предсказания на тестовом наборе;
4. вычислять метрики качества обученной модели;
5. сохранять обученную модель;
6. выполнять автотесты и визуализировать метрики.

Система реализуется как Python-пакет без собственного контейнера,
сервиса и порта: переиспользуется общий стенд `infra/` и окружение
`dz2-ui-1` по аналогии с Dz8, но в рамках ДЗ9 это не требуется.

### 1.1. Что считается успехом

- датасет загружается, корректно разбивается на train/test;
- модель обучается без ошибок и сохраняется;
- предсказания на test-взятии получаются;
- метрики (accuracy, precision, recall) вычисляются и согласуются с
  ручным расчётом на микродатасете;
- автотесты из задачи проходят;
- график метрик сохраняется;
- конвейер прогнан для каждого выбранного датасета из registry.

## 4. Термины

| Термин | Определение |
|---|---|
| **Датасет** | CSV-набор: признаки + бинарная метка `label ∈ {0, 1}`. |
| **Train / Test split** | Обучающая и тестовая выборки; стратификация при бинарной метке. |
| **Смещение (leakage)** | Использование информации тестовой выборки при обучении. |
| **accuracy** | `(TP + TN) / N`. |
| **precision** | `TP / (TP + FP)`. |
| **recall** | `TP / (TP + FN)`. |
| **TP / FP / FN / TN** | true positive / false positive / false negative / true negative. |

### 5.2. Поток данных

```
data/<dataset>.csv
    │
    ▼

    │
    ▼
model.build → train.fit
    │
    ▼
```

`pima_indians`; выбранный ключ задаётся в конфиге и выполняет конвейер.
(Дизайн — `openspec/changes/add-model-quality-lab/design.md`.)

## 6. Загрузка датасета и разбиение (FR-1)

- `load_dataset(name) -> DatasetSplit` SHALL читать CSV с колонками
  признаков и бинарной меткой `label ∈ {0, 1}`;
  формат размеченного CSV: колонки `feature_1…feature_N` + `label ∈ {0, 1}`.
- Система SHALL разделять данные на train/test с `test_size=0.2`,
  `random_state=42`, `stratify=y` при бинарной метке.
- Система SHALL проверять: непустой файл, наличие `label`, допустимые
  значения метки, наличие двух классов в обучающей выборке.
- Разбиение SHALL быть стратифицированным и без пересечения.
- Система SHALL поддерживать несколько датасетов через registry:
  `breast_cancer` (встроенный в scikit-learn) и `pima_indians` (UCI, через
  `fetch_openml`/CSV).
- Система SHALL выполнять конвейер для датасета, выбранного ключом
  конфигурации (`dataset`), и отдельно — для второго (последовательные
  прогон/запуск по ключу).
- Для пользовательского датасета достаточно положить файл в `dz9/data/` и
  передать локатор `csv:<path>`.

#### Scenario: Корректное разбиение

- **WHEN** датасет загружен
- **THEN** `len(train) + len(test) == len(dataset)`
- **AND** пересечение train/test пусто
- **AND** дисбаланс классов сохранён стратификацией.

#### Scenario: Некорректный датасет

- **WHEN** датасет без метки `label` или с меткой вне `{0, 1}`
- **THEN** загрузка завершается ошибкой (исключение/ошибка конфигурации).

#### Scenario: Сторонний датасет

- **WHEN** задан локатор `csv:<path>` на внешний CSV
- **THEN** файл SHALL быть прочитан по ожидаемому формату
  (`feature_*` + бинарная `label`)
- **AND** дальше SHALL следовать тот же split и метрики.

## 7. Модель и обучение (FR-2)

- Система SHALL реализовывать модель классификации (скользящий
  перцептрон / логистическая регрессия) на Python 3.
- Система SHALL обучать модель на train-признаках и train-метках.
- Обучение SHALL быть детерминированным при фиксированном seed.
- Система SHALL сохранявать модель (persist) и восстанавливать её.

#### Scenario: Обучение

- **WHEN** модель обучается на малой синтетической выборке
- **THEN** `fit` завершается без ошибки и выдаёт обученную модель.

---

## 8. Предсказания и метрики (FR-3, FR-4)

- Система SHALL выполнять предсказания на test-признаках.
- Метрики SHALL вычисляться по confusion matrix:
  - `accuracy = (TP + TN) / N`;
  - `precision = TP / (TP + FP)`;
  - `recall = TP / (TP + FN)`.

#### Scenario: Метрики на микроданных

- **WHEN** истинная метка `y_true = [1, 0, 1, 1]`, предсказание
  `y_pred = [1, 0, 0, 1]`
- **THEN** `TP = 2`, `TN = 1`, `FP = 0`, `FN = 1`
- **AND** `accuracy = 0.75`, `precision = 1.0`, `recall = 0.67`.

#### Scenario: Нулевой знаменатель у precision

- **WHEN** `TP + FP = 0` (предсказанных положительных нет)
- **THEN** `precision = 0.0` (fail-safe, без деления на ноль).

#### Scenario: Нулевой знаменатель у recall

- **WHEN** `TP + FN = 0` (истинных положительных нет)
- **THEN** `recall = 0.0` (fail-safe, без деления на ноль).
