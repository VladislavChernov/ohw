# Proposal: запросы к локальной LLM через движок

## Зачем

Нужен простой движок, который автоматизирует отправку запросов локальной LLM:
пользователь кладёт файл с текстом запроса в папку `input`, движок читает его,
посылает локальной модели (ollama в Docker) и кладёт ответ модели в папку
`output`. Это учебный проект (Otus): цель — освоить связку Python + uv +
Docker + Dev Container + локальный LLM-инференс.

## Что делаем

CLI-программа на Python:

1. Читает файлы запросов из входной папки (`--input-dir`, по умолчанию
   `./input`): каждый файл — обычный текст или markdown (.txt/.md) с запросом.
2. Подключается к локальному ollama-контейнеру (адрес из `OLLAMA_BASE_URL`,
   модель из `OLLAMA_MODEL`).
3. По каждому файлу отправляет запрос на генерацию ответа (chat completion
   без специфичных для проекта структур).
4. Записывает ответ модели по каждому файлу в выходную папку
   (`--output-dir`, по умолчанию `./output`): `<имя входного файла>.md`.

Программа сама упаковывается в docker-контейнер и поднимается вместе с
ollama через Docker Compose одной командой.

## Ограничения

- Модель локальная, запускается контейнером `ollama/ollama`; GPU NVIDIA
  (RTX 2070 SUPER, 8 GB VRAM) — на машине автора, CPU — универсальный fallback.
- Параметры генерации должны укладываться в контекст модели; большие запросы
  не дробим без необходимости.
- Движок «лёгкий»: без сложного конвейера артефактов — файл запроса →
  один промпт в LLM → ответ модели в markdown-файл.

## Изменения

- Новый проект `light-llm-engine`:
  - Python-пакет с CLI (`argparse`), менеджер зависимостей — `uv`;
  - модуль интеграции с Ollama HTTP API (`/api/chat`);
  - чтение входных файлов и запись markdown-ответов;
  - `Dockerfile` + `compose.yaml` (сервисы `ollama` и `app`);
  - `.devcontainer` для VS Code;
  - тесты (pytest): unit на клиент/чтение/запись, integration — помечены
    маркером и требуют живого ollama.

## Impact

- Код: новый проект, обратной совместимости нет.
- Инфраструктура: собственный compose-стек (ollama + app); новые
  долгоживущие сервисы не выводятся за пределы проекта.
