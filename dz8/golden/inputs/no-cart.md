# Требования к каталогу курсов

**URL:** https://otus.ru/catalog/courses

## Requirements

### BR-1
Каталог отображает список курсов с названием, направлением и кратким описанием.

### BR-2
Пользователь может отфильтровать курсы по направлению подготовки.

### BR-3
Карточка курса открывается по ссылке и показывает программу обучения.

### BR-4
Поиск по названию курса возвращает подходящие карточки каталога.
