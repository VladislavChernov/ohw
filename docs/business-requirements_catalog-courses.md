# Бизнес-требования: страница «Каталог курсов — Программирование»

**URL:** https://otus.ru/catalog/courses?categories=programming

Только функциональные требования, проверяемые любым посетителем
с первого захода (чёрный ящик, без доступа к бэкенду и аналитике).

| ID | Требование |
|----|------------|
| BR-1 | При открытии ссылки каталог показывает только курсы направления «Программирование»; посторонних курсов в выдаче нет |
| BR-2 | Карточка курса до перехода внутрь даёт достаточно информации для решения: название, длительность или дата старта, стоимость (или признак «бесплатно» / «старт скоро»), кнопка или ссылка действия («Записаться», «Подробнее») |
| BR-3 | Клик по карточке открывает страницу этого курса; переход не заканчивается ошибкой или 404 |
| BR-4 | Фильтры на странице реально меняют список курсов; сброс фильтров возвращает исходную выдачу |
| BR-5 | Выбранное состояние фильтра видно в адресной строке (`?categories=...`); ссылку можно открыть заново и увидеть тот же отфильтрованный список |
| BR-6 | Пагинация работает: переключатель страниц присутствует, переход на следующую страницу меняет состав выдачи (курсы не дублируют предыдущую страницу), возврат на предыдущую страницу работает, номер страницы виден в адресной строке (`&page=2`) |
| BR-7 | Некорректные параметры адресной строки не ломают страницу: несуществующая категория или номер страницы за пределами списка дают пустую выдачу либо корректное сообщение, а не ошибку сервера |
