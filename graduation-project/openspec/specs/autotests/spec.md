# Specification: API Test Seam

## Назначение

Шов для будущих исполняемых API-тестов. Сегодня не вызывает сеть и не меняет
поведение проекта без явного флага. Контракт стабилен: адаптер ДЗ3 advanced
подключается позже без переделки workflow, моделей и отчёта.

## EARS Requirements

### SHALL

- **SHALL** предоставлять порт `ApiTestRunner` с методом
  `run(request) -> ApiTestReport`; внутренние типы плана адаптера не входят
  в контракт.
- **SHALL** принимать `--api-tests`, `--api-base-url`, `--api-contract`,
  `--api-cases`.
- **SHALL** выполнять фазу API-тестов только при явном `--api-tests`.
- **SHALL** сохранять результат в `output/api-tests.json` с полями `runner`,
  `base_url`, `model`, `generated_at`, `total`, `passed`, `failed`,
  `duration_ms`, `cases`, `errors`.
- **SHALL** добавлять в `quality-metrics.json` необязательный ключ `api_tests`
  только при выполненной фазе.
- **SHALL** добавлять раздел `## API-тесты` в `report.md` только при наличии
  данных.
- **SHALL** оставлять `overall` и четыре метрики документации неизменными.
- **SHALL** возвращать код 2, если `--api-tests` указан без `--api-base-url`
  или без подключённого раннера.
- **SHALL** записывать ошибку отдельного кейса в `cases` и `errors`, продолжая
  остальные кейсы.
- **SHALL** возвращать код 4 при ошибке записи `api-tests.json`.

### WHEN/THEN

- **WHEN** `--api-tests` не указан
- **THEN** фаза не выполняется, `api-tests.json` не создаётся, `report.md` и
  `quality-metrics.json` побайтово соответствуют текущему поведению.

- **WHEN** раннер не подключён, а `--api-tests` указан
- **THEN** CLI печатает понятное сообщение о том, что адаптер не подключён, и
  возвращает код 2.

- **WHEN** кейс завершился ошибкой транспорта
- **THEN** он попадает в `failed` с текстом ошибки, прогон продолжается.

- **WHEN** фаза выполнена и `report` запускается отдельно
- **THEN** раздел `## API-тесты` восстанавливается из `api-tests.json`.

## Границы

- Сеть, LLM и HTTP-вызовы в текущей реализации отсутствуют.
- ДЗ3 advanced, ДЗ6 и HTTP-фасад проекта в этот шаг не входят.
- Исполнительные результаты не влияют на `overall`, `--fail-under` и графики.
