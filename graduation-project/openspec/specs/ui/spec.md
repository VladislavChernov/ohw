# Specification: Streamlit Workbench

## Назначение

Второй фронт проекта: интерактивное рабочее место поверх тех же стадий, что и
CLI. UI не дублирует бизнес-логику и не меняет поведение CLI.

## EARS Requirements

### SHALL

- **SHALL** предоставлять Streamlit-приложение `src/ui/app.py` с вкладками
  «Требования», «Промпт», «Генерация», «Метрики», «Отчёт».
- **SHALL** использовать общие стадии `src/workflow/stages.py`; CLI и UI
  вызывают один и тот же код генерации, оценки, визуализации и отчёта.
- **SHALL** принимать `.md` и `.txt`, позволять редактировать текст и сохранять
  его в `output/ui-input/`.
- **SHALL** принимать URL, тип артефакта, число кейсов, число повторов,
  нормализацию и пресеты.
- **SHALL** собирать промпт из шаблона DZ7 и выбранных пресетов, показывать его
  целиком и позволять отредактировать; правка применяется к выбранному файлу.
- **SHALL** показывать средние метрики, таблицу по сценариям и графики после
  соответствующих стадий.
- **SHALL** показывать `report.md` и давать скачать артефакты, отчёт и JSON.
- **SHALL** опрашивать Ollama только по явной кнопке, не при старте.
- **SHALL** показывать понятную ошибку, если модель не задана или Ollama
  недоступна.
- **SHALL** предоставлять Docker-сервис `ui` на порту `8501`.
- **SHALL** сохранять поведение CLI без изменений.

### WHEN/THEN

- **WHEN** файлы не загружены
- **THEN** вкладки показывают подсказку, генерация недоступна.

- **WHEN** пользователь нажимает «Сгенерировать»
- **THEN** файлы копируются в `output/ui-input/`, выполняется генерация, а
  результат показывается в сессии без перезапуска CLI.

- **WHEN** пользователь редактирует промпт на вкладке «Промпт»
- **THEN** генерация использует этот текст для выбранного файла, а остальные
  файлы собирают промпт из шаблона.

- **WHEN** генерация завершилась ошибкой одного файла
- **THEN** ошибка показывается, а успешные сценарии остаются доступны.

- **WHEN** UI открывается без Ollama
- **THEN** приложение отрисовывается, сетевые запросы не выполняются.

## Границы

- Нет аутентификации и многопользовательского режима.
- Нет фоновых заданий: генерация идёт в запросе Streamlit.
- Нет новых метрик и типов артефактов.
- API-тесты не входят в проект.
