# Specification: Pipeline Contract and Recovery

## Назначение

Контракт файлов между фазами и поведение при сбоях генерации. Спецификация
дополняет `openspec/specs/generation/spec.md`: генерация описывает, что
производится, а пайплайн — как артефакты читаются следующими фазами.

## EARS Requirements

### SHALL

- **SHALL** хранить версию контракта в единственной константе
  `PIPELINE_VERSION` в `src/config.py`.
- **SHALL** записывать `pipeline_version` в `generation.json` и
  `quality-metrics.json`.
- **SHALL** принимать файлы без `pipeline_version` как legacy-артефакты и
  читать их без ошибки.
- **SHALL** отклонять файлы с `pipeline_version`, отличной от
  `PIPELINE_VERSION`, с понятной ошибкой, называющей файл, версию файла и
  текущую версию.
- **SHALL** сохранять код возврата `2` для несовпадения версии: это ошибка
  входных данных, а не сбой генерации.
- **SHALL** по умолчанию прерывать генерацию при `OllamaConnectionError`.
- **SHALL** продолжать обработку остальных файлов при `OllamaConnectionError`,
  если включён `continue_on_error`.
- **SHALL** записывать ошибку проблемного файла в `errors` при включённом
  продолжении и сохранять успешные сценарии.
- **SHALL** возвращать код `3`, если при продолжении не сгенерирован ни один
  сценарий.

### WHEN/THEN

- **WHEN** `generation.json` записан текущей версией
- **THEN** `--assess` читает его без предупреждений.
- **WHEN** в `generation.json` нет ключа `pipeline_version`
- **THEN** снимок читается как legacy, и оценка выполняется по сохранённым
  данным.
- **WHEN** `pipeline_version` в файле не совпадает с текущей
- **THEN** CLI печатает понятную ошибку и возвращает код `2`; файл не читается.
- **WHEN** `--continue-on-error` не задан и Ollama недоступна
- **THEN** генерация прерывается с кодом `3`.
- **WHEN** `--continue-on-error` задан и Ollama недоступна для одного файла
- **THEN** ошибка попадает в `errors`, остальные файлы обрабатываются, а
  успешные сценарии доступны следующим фазам.
- **WHEN** в UI включён чекбокс «Продолжать при ошибке Ollama»
- **THEN** UI ведёт себя так же, как CLI с `--continue-on-error`.

## Границы

- Версия не мигрирует старые файлы автоматически.
- Проверяется только совместимость контракта, а не полнота каждого поля.
- Ошибки записи на диск не считаются per-file recovery и завершают прогон.
