# Specification: Quality Assessment

## EARS Requirements

### SHALL

- **SHALL** рассчитывать читаемость (Readability) по средней длине предложения:
  оптимум 17 слов, линейный штраф до 0 на расстоянии 30 слов.
- **SHALL** рассчитывать чёткость целей (Clarity of goals) как долю пяти
  независимых категорий измеримых формулировок; каждая категория добавляет 0.2.
- **SHALL** рассчитывать покрытие требований (Scenario coverage) как долю
  уникальных `BR-N` из входного файла, упомянутых в сгенерированном тексте.
- **SHALL** рассчитывать консистентность (Consistency) как среднюю попарную
  Jaccard-близость множеств слов повторных генераций при `--runs N ≥ 2`.
- **SHALL** использовать внутреннюю эвристику при `--runs 1`: 0.8 для
  последовательной нумерации `BR-N` без пропусков, иначе 0.5.
- **SHALL** возвращать `None`, если метрика не измерима, и печатать её как `n/a`;
  `None` не заменяется нулём.
- **SHALL** считать `overall` взвешенным средним известных метрик с
  перенормировкой весов: readability 0.25, clarity 0.25, coverage 0.30,
  consistency 0.20.
- **SHALL** агрегировать метрики по сценариям, игнорируя `None`.
- **SHALL** считать сценарий успешным при `overall ≥ 0.5`.
- **SHALL** сохранять метрики в `quality-metrics.json` и дублировать их в
  `report.md`; JSON — источник правды.

### Формулы

- Readability: `clamp(1 - |avg_words_per_sentence - 17| / 30, 0, 1)`.
- Clarity: `0.2 × количество найденных категорий`.
- Coverage: `|expected ∩ found| / |expected|`; `None`, если `expected` пуст.
- Consistency: среднее по всем парам `|A ∩ B| / |A ∪ B|`; `None`, если меньше
  двух генераций.
- Overall: `Σ(w_i × metric_i) / Σ(w_i)` по известным метрикам; 0.0, если
  известных метрик нет.

### WHEN/THEN

- **WHEN** во входном файле нет `BR-N`
- **THEN** `scenario_coverage = None`, `overall` считается по остальным метрикам,
  а в отчёте печатается `n/a`.
- **WHEN** `--runs 1`
- **THEN** `consistency` — внутренняя эвристика, а не воспроизводимость.
- **WHEN** `--runs 2` и более
- **THEN** `consistency` — средняя Jaccard-близость всех пар генераций.
- **WHEN** все сценарии имеют `overall < 0.5`
- **THEN** в отчёте все они помечены как «требует доработки».
- **WHEN** задан `--fail-under SCORE`
- **THEN** CLI возвращает код 5, если средний `overall < SCORE`; если `overall`
  не измерим, проверка пропускается с предупреждением.
