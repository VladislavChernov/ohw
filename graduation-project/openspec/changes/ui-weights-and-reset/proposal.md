# Предложение: доделать рабочее место UI

## Зачем

UI использует общие стадии с CLI, но до сих пор не позволяет задать веса
`overall` и не может сбросить состояние между прогонами. Это расхождение с CLI
(там есть `--quality-weights`) и неудобство при отладке: после неудачного
прогона данные прошлой генерации остаются в `session_state`. Дополнительно
в подсказках вкладок «Метрики» и «Отчёт» указан неверный номер вкладки
генерации.

## Что меняется

1. Панель весов `overall` в сайдбаре: четыре числовых поля, валидация через
   `validate_quality_weights`, печать канонической строки.
2. Веса передаются в `GenerationRequest` и сохраняются в артефактах; вкладка
   «Метрики» показывает использованные веса.
3. Кнопка «Очистить состояние» в сайдбаре: сбрасывает `session_state` к значениям
   по умолчанию без изменения файлов на диске.
4. Исправлены подсказки «вкладка 2» → «вкладка 3».
5. Тесты AppTest: кастомные веса, неверная сумма, очистка состояния.
6. Обновлены README, user guide, CONCEPT, CHANGELOG и SDD.

## Что не меняется

- Пять вкладок и общие стадии `src/workflow/stages.py`.
- LRU для `session_state` не вводится: состояние маленькое, достаточно явного
  сброса.
- Формулы метрик и поведение CLI. `PIPELINE_VERSION` остаётся `0.1.0`.

## Критерии приёмки

- При валидных весах `0.4 / 0.2 / 0.2 / 0.2` снимок содержит их в
  `quality_weights`, а `report.md` — строку весов.
- При неверной сумме UI показывает ошибку и не запускает генерацию.
- Кнопка очистки возвращает состояние к значениям по умолчанию.
