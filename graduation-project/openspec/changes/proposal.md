# Предложение по scopes выпускного проекта

## Minimal Viable Product (MVP)
1. Генерация 5 типов тест-документации через Ollama (на базе DZ2)
2. Оценка качества с 2 NLP метрики (читаемость, консистентность)
3. JSON отчет с метриками
4. Markdown отчет в требуемом формате

## Expanded Scope
1. Полные 4 NLP метрики (читаемость, четкость целей, покрытие сценариев, консистентность)
2. Генерация датасетов good/bad сценариев через Ollama
3. Визуализация метриками matplotlib/seaborn
4. Streamlit вкладка для интерактивной оценки
5. Расширенная отчетность с аналитикой
