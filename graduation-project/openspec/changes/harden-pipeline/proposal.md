# Предложение: устойчивый пайплайн (P0 ревью)

## Зачем

Ревью Senior+ выявило два пробела, которые важнее остальных:

1. **Контракт артефактов не версионирован.** `generation.json` и
   `quality-metrics.json` читаются последующими фазами, но не сообщают, какой
   версией пайплайна они записаны. После изменения формата старый файл может
   быть молча прочитан неверно.
2. **Недоступность Ollama обрывает весь прогон.** Один сетевой сбой убивает
   обработку остальных файлов, хотя ошибки модели уже обрабатываются per-file.

Оба пункта входят в P0 предложения по изменениям и должны быть закрыты до
релиза `0.1.0`.

## Что входит

1. Единая константа `PIPELINE_VERSION` в `src/config.py`.
2. Ключ `pipeline_version` в `generation.json` и `quality-metrics.json`.
3. Валидация версии в `load_snapshot` и `load_pipeline_data`:
   - ключа нет — файл считается legacy и читается;
   - версия не совпадает — понятная ошибка с указанием файла и версий.
4. `GenerationRequest.continue_on_error` и CLI-флаг `--continue-on-error`.
5. Переключатель «Продолжать при ошибке Ollama» на вкладке «Генерация» в UI.
6. Тесты: наличие версии, legacy-файл, несовпадение версии, per-file recovery,
   CLI-флаг, UI-переключатель.
7. Документация: OpenSpec, SDD, README, `docs/user-guide.md`.

## Что не входит

- Автоматическая миграция старых `generation.json` и `quality-metrics.json`.
- Configurable quality weights, schema validation, dry-run, пересмотр
  `clarity` и прочие P1/P2 из `CHANGE_PROPOSAL.md`.
- Изменение формул метрик и состава артефактов.

## Поведение по умолчанию

- Без `--continue-on-error` ошибка соединения с Ollama прерывает генерацию, как
  раньше; CLI возвращает код `3`.
- С `--continue-on-error` ошибка соединения записывается в `errors` для
  текущего файла, остальные файлы обрабатываются. Если не сгенерирован ни один
  сценарий, CLI всё равно возвращает код `3`, но снимок с ошибками сохранён.
- Ошибки модели и валидатора (`GenerationError`, `OllamaResponseError`) не
  останавливают остальные файлы независимо от флага.

## Критерии приёмки

- Новые `generation.json` и `quality-metrics.json` содержат
  `pipeline_version = "0.1.0"`.
- Файлы без `pipeline_version` читаются как legacy.
- Файл с другой версией даёт `ValueError` с понятным русским сообщением.
- Смешанный прогон (один файл с ошибкой соединения, второй успешный)
  завершается с одним сценарием и одной ошибкой при `--continue-on-error`.
- Без флага тот же прогон прерывается.
- `pytest`, `ruff`, `mypy` зелёные; живой e2e проходит.
