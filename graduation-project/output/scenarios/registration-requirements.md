# Тест-кейсы: registration-requirements

**Всего кейсов:** 4 (позитивных: 2, негативных: 2)

## Позитивные сценарии

### TC-01. Успешная регистрация с корректными данными

**Тип:** позитивный

**Проверяет требование:** BR-5

**Предусловия:**

- Пользователь на странице регистрации

**Шаги:**

| № | Действие |
|---|----------|
| 1 | Открыть страницу регистрации |
| 2 | Заполнить поле 'Email' корректным email-адресом |
| 3 | Заполнить поле 'Пароль' паролем, содержащим не менее 8 символов, одну цифру и одну заглавную букву |
| 4 | Заполнить поле 'Повтор пароля' тем же паролем |
| 5 | Нажать кнопку 'Зарегистрироваться' |

**Ожидаемый результат:** Появляется сообщение об успешной регистрации, пользователь перенаправляется на страницу личного кабинета
