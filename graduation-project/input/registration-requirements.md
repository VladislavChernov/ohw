# Требования: форма регистрации

## BR-1. Открытие формы
Пользователь открывает страницу регистрации. Форма должна содержать поля
«Email», «Пароль», «Повтор пароля» и кнопку «Зарегистрироваться».

## BR-2. Валидация email
Email должен соответствовать формату `user@example.com`. При некорректном
email должно отображаться сообщение «Введите корректный email».

## BR-3. Сложность пароля
Пароль должен содержать не менее 8 символов, хотя бы одну цифру и одну
заглавную букву. При нарушении — сообщение «Пароль слишком простой».

## BR-4. Совпадение паролей
Значения полей «Пароль» и «Повтор пароля» должны совпадать. При несовпадении
должно отображаться сообщение «Пароли не совпадают».

## BR-5. Успешная регистрация
При корректных данных должен создаваться аккаунт, после чего пользователь
перенаправляется на страницу личного кабинета.
