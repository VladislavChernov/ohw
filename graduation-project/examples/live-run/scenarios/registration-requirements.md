# Тест-кейсы: registration-requirements

**Всего кейсов:** 4 (позитивных: 2, негативных: 2)

## Позитивные сценарии

### TC-01. Открытие формы регистрации

**Тип:** позитивный

**Проверяет требование:** BR-1

**Предусловия:**

- Пользователь находит ссылку на страницу регистрации

**Шаги:**

| № | Действие |
|---|----------|
| 1 | Нажать на ссылку 'Регистрация' |

**Ожидаемый результат:** Открыта страница с формой регистрации, содержащей поля 'Email', 'Пароль', 'Повтор пароля' и кнопку 'Зарегистрироваться'.

### TC-02. Успешная регистрация с корректными данными

**Тип:** позитивный

**Проверяет требование:** BR-5

**Предусловия:**

- Пользователь на странице регистрации

**Шаги:**

| № | Действие |
|---|----------|
| 1 | Ввести корректный email в поле 'Email' |
| 2 | Ввести пароль, удовлетворяющий требованиям, в поле 'Пароль' |
| 3 | Повторить пароль в поле 'Повтор пароля' |
| 4 | Нажать на кнопку 'Зарегистрироваться' |

**Ожидаемый результат:** Создан аккаунт, пользователь перенаправлен на страницу личного кабинета.

## Негативные сценарии

### TC-03. Некорректный email при регистрации

**Тип:** негативный

**Проверяет требование:** BR-2

**Предусловия:**

- Пользователь на странице регистрации

**Шаги:**

| № | Действие |
|---|----------|
| 1 | Ввести некорректный email в поле 'Email' |
| 2 | Ввести пароль, удовлетворяющий требованиям, в поле 'Пароль' |
| 3 | Повторить пароль в поле 'Повтор пароля' |
| 4 | Нажать на кнопку 'Зарегистрироваться' |

**Ожидаемый результат:** Поле 'Email' подсвечивается красным цветом с сообщением 'Введите корректный email'.

### TC-04. Пароль не соответствует требованиям при регистрации

**Тип:** негативный

**Проверяет требование:** BR-3

**Предусловия:**

- Пользователь на странице регистрации

**Шаги:**

| № | Действие |
|---|----------|
| 1 | Ввести email в поле 'Email' |
| 2 | Ввести пароль, не удовлетворяющий требованиям, в поле 'Пароль' |
| 3 | Повторить пароль в поле 'Повтор пароля' |
| 4 | Нажать на кнопку 'Зарегистрироваться' |

**Ожидаемый результат:** Поле 'Пароль' подсвечивается красным цветом с сообщением 'Пароль слишком простой'.
