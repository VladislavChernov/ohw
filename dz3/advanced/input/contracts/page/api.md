# JSONPlaceholder

Бесплатный фейковый REST API для тестирования и прототипирования.

- Базовый URL: `https://jsonplaceholder.typicode.com`
- Ресурсы: `/posts`, `/comments`, `/albums`, `/photos`, `/todos`, `/users`
- Каждый ресурс поддерживает стандартные CRUD-операции (list, get, create, update, patch, delete).
- Все изменяющие операции имитируются: сервер не сохраняет изменения и возвращает отправленное тело.
- Ответы — JSON-массивы (для list) или JSON-объекты (для одиночных ресурсов).
- Коды статусов: 200 OK для get/put/patch/delete, 201 Created для post.
- Для тестирования используй реалистичные данные (посты, комментарии, альбомы, фото, задачи, пользователи).
