arc42 / C4 ARCHITECTURE PASSPORT -- LEVEL 1: SYSTEM CONTEXT (v6.0.0)
РАЗДЕЛ arc42: БИЗНЕС-КОНТЕКСТ И ГРАНИЦЫ СИСТЕМЫ (CONTEXT & SCOPE)

Гибридная платформа GraphRAG v6 представляет собой изолированное, автономно функционирующий 
программный комплекс в закрытом сетевом периметре предприятия. Платформа агрегирует неструктурированные 
инженерные знания из корпоративных систем, строит детерминированный граф связей, производит семантическую 
валидацию требований и обеспечивает контекстный поиск через кастомные API-адаптеры.

ДИАГРАММА СИСТЕМНОГО КОНТЕКСТА C4 (LEVEL 1)

[ Внешние Пользователи / Потребители Знаний ]
│── (А) Бизнес- и Системные Аналитики : Формируют ТЗ, спецификации, контролируют коллизии.
│── (Б) Инженеры и Разработчики ПО     : Запрашивают архитектурные схемы и кодовые зависимости.
└── (В) Автономные ИИ-Агенты (Cursor) : Выполняют чтение графа знаний через MCP-шлюз.

[ Внешние Инфраструктурные Источники (Входной поток данных) ]
│── (Г) Git-репозитории (GitLab)      : Поставляют JSON-схемы, файлы конфигураций и исходный код.
│── (Д) Системы управления знаниями   : Текстовые регламенты, проектная документация, Confluence/Wiki.
└── (Е) Системы трекинга задач (Jira)  : Поставляют идентификаторы дефектов и связанных тест-кейсов.

ТРАНСПОРТНЫЙ КОНТРАКТ НА ГРАНИЦЕ СИСТЕМЫ
* Входные интерфейсы: REST HTTP JSON для шлюзов Query API (8000), Config API (8001), Ingestion API (8002).
* Выходные потоки: Двунаправленный асинхронный стриминг токенов по протоколам WebSockets и SSE для 
  исключения блокировок входящих веб-потоков.
