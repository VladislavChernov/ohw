ПЛАТФОРМЕННЫЙ КОНФИГУРАТОР v6: РАЗДЕЛЕНИЕ ИНТЕРФЕЙСОВ УПРАВЛЕНИЯ (GUI)

Для исключения логического смешения инфраструктурных и бизнес-параметров, управляющая 
административная панель (Streamlit) жестко разделена на два иерархических контекстных экрана. 
Само ядро микросервисов остается технологически инвариантным и ничего не знает о специфике данных.

ЭКРАН 1: "БИЗНЕС-ОНТОЛОГИЯ" (Контекст Аналитиков и Лингвистических Экспертов)
Полностью очищен от технических терминов БД и параметров GPU. Управляет логикой Domain Profile:

[ Панель управления бизнес-контентом профиля ] ───────────────────────────────────────────+
│                                                                                         │
│  Активный домен системы: [ ИТ-Спецификации / it  ▼ ]                                    │
│                                                                                         │
│  Доменная Онтология (Node Types):                                                       │
│  [+] Добавить категорию  │  (:Requirement), (:Concept), (:Contract)                     │
│                                                                                         │
│  Валидационные правила связей (Edge Types):                                             │
│  [+] Добавить связь      │  (:Requirement)-[:REQUIRES]->(:Concept)                       │
│                          │  (:Concept)-[:EXTENDS]->(:Contract)                           │
│                                                                                         │
│  Канонический Глоссарий Нормализатора (Glossary Mapping):                               │
│  Канонический Термин        Синонимы / Строковые Варианты Записи                        │
│  ───────────────────────    ──────────────────────────────────────────────────────────  │
│  log                        lg, ln, log_2, log2, logn, log₂                             │
│  christopher_nolan          Кристофер Нолан, К. Нолан, Нолан, Christopher Nolan         │
│                                                                                         │
+─────────────────────────────────────────────────────────────────────────────────────────+
Механика: При сохранении GUI-форма компилирует чистый, валидный `domain_profile.yaml` и глоссарий, 
отправляя их по REST-контракту в Config Service (порт 8001). Система перестраивает онтологию в рантайме.

ЭКРАН 2: "ТОПОЛОГИЯ ИНФРАСТРУКТУРЫ" (Контекст DevOps-инженеров и Архитекторов Системы)
Вход защищен системной авторизацией (`namespace: auth`). Напрямую управляет Topology Orchestrator:

[ Панель конфигурации системной топологии ] ──────────────────────────────────────────────+
│                                                                                         │
│  Инфраструктурные переключатели (Feature Flags):                                        │
│  [X] async_ingestion_enabled  ──► Активировать обработку через RabbitMQ воркеры.       │
│  [X] cache_enabled            ──► Включить оперативную память Valkey.                   │
│  [X] semantic_cache_enabled   ──► Разрешить семантический отсев в ОЗУ.                  │
│  [X] mcp_gateway_enabled      ──► Открыть RPC-порт взаимодействия для внешних ИИ-агентов.│
│                                                                                         │
│  Слой Адаптеров Платформы (Runtime Plug-in Configuration):                              │
│  Драйвер Хранилища (Storage) : [ Neo4j gRPC Driver (Neo4jGrpcAdapter)               ▼ ] │
│  Инференс-движок (LLM Base)  : [ vLLM Engine Client (VllmAdapter)                   ▼ ] │
│  Сервис Эмбеддингов (Embed)  : [ Локальный контейнер (LocalSentenceTransformerAdapter)▼ ] │
│  Модуль Переранжирования      : [ bge-reranker-base (CPU)                           ▼ ] │
│                                                                                         │
+─────────────────────────────────────────────────────────────────────────────────────────+
Механика: Изменения через Topology Orchestrator на лету подменяют InMemory-классы сетевыми 
драйверами (Redis/RabbitMQ/Qdrant) без деплоя и перезапуска контейнеров ядра.
