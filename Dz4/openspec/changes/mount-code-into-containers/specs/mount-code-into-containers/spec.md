# Delta Spec: mount-code-into-containers

## ADDED Requirements

### Requirement: Актуальность кода в контейнере

Сервис, исполняющий код проекта, получает исходники через том `../src → /app/src:ro`
при каждом запуске. Пересборка образа для актуальности кода не требуется: пакет
установлен в режиме редактирования (`graphrag_proto.pth` = `/app/src`), и том перекрывает
путь импорта.

Образ при этом несёт только внешнее: зависимости и venv, модель NER, llama.cpp и модель.

#### Scenario: Правка исходника видна без пересборки

- **WHEN** в файл `prototype/src/graphrag_proto/pre_ingest/generate.py` внесена правка и
  запущен `docker compose -f compose.preingest.yaml run --rm pre-ingest`
- **THEN** контейнер видит правку, то есть число шаблонов в контейнере равно числу в
  `CANDIDATE_PATTERNS` рабочей копии, и `docker build` не выполнялся

#### Scenario: Образ не содержит кода как источника актуальности

- **WHEN** образ `Dockerfile` собран и в нём работает любой сервис нашего кода
- **THEN** изменение в `prototype/src` без пересборки обрата не меняет поведение
  контейнера, потому что каталог перекрыт томом

### Requirement: Внешние инструменты не получают исходники

`llm` и `reranker` — это llama.cpp и модель реранкера; наш код в них не исполняется.
Монтирование исходников в такой сервис считается ошибкой, а не избыточностью.

#### Scenario: Попытка смонтировать исходники во внешний инструмент

- **WHEN** в `compose.runtime.yaml` сервису `llm` добавлен том `../src:/app/src`
- **THEN** `check_mounts.ps1` завершается кодом 1 с сообщением «source mounted into
  external tool»

#### Scenario: Наш сервис без build-контекста

- **WHEN** сервис объявлен с образом из пространства `ohw/*` и без секции `build`
- **THEN** он считается сервисом нашего кода, и монтирование для него обязательно; если
  образ не собран, сервис выводится в раздел «объявлен, но не запускается», а не
  пропускается молча

### Requirement: Оверлей не теряет монтирование

Compose заменяет список `volumes` целиком, а не дополняет его. Поэтому том, добавленный
только в базовый compose-файл, при наложении оверлея исчезает без всякой ошибки.

#### Scenario: Монтирование переживает наложение оверлея

- **WHEN** `compose.runtime.yaml` дополнен `compose.ingest.yaml`
- **THEN** сервисы нашего кода сохраняют монтирование `/app/src`, и это видно в
  разрешённой конфигурации, а не в исходном тексте

### Requirement: Приборы проверки не проходят молча

Прибор, не нашедший ни одного объекта проверки, обязан сообщить об этом и завершиться
ненулевым кодом. Пустой вход и отсутствие расхождений — разные результаты.

#### Scenario: Compose разрешил ноль сервисов

- **WHEN** `check_mounts.ps1` запущен без `--profile *` и compose возвращает пустую карту
  сервисов
- **THEN** прибор завершается кодом 2 с сообщением «check is vacuous», а не PASS

#### Scenario: Число проверенных не совпало с ожидаемым

- **WHEN** число сервисов нашего кода вычислено по конфигурации и не совпало с числом
  реально проверенных
- **THEN** прибор завершается кодом 2 с сообщением о пробеле в покрытии

#### Scenario: Проверка кандидатов на пустом корпусе

- **WHEN** `verify_candidates.py` запущен на папке без файлов `.md`
- **THEN** прибор завершается кодом 2 со словами «не измерено», а не сообщает о
  согласованности

### Requirement: Дефолтные пути указывают на корпус

Дефолт в compose не должен разрешаться в каталог, где нет документов: пустой результат
там выглядит как «корпус пуст», а не как ошибка конфигурации.

#### Scenario: Запуск pre-ingest без переменных

- **WHEN** `docker compose -f compose.preingest.yaml run --rm pre-ingest` запущен без
  `PRE_INGEST_SRC`
- **THEN** путь разрешается в корневой `docs/` репозитория, где есть `.md`, а не в
  `prototype/docs`, где их нет

#### Scenario: Неверный путь молча создаёт пустой каталог

- **WHEN** том указывает на несуществующий каталог, например `../pre-ingest` вместо
  `../../pre-ingest`
- **THEN** docker создаёт пустой каталог и монтирует его; контейнер видит ноль
  кандидатов, ингест уходит в vector-only, все джобы завершаются `succeeded`, а графа нет
