# Spec: контракт золотого набора после ревизии

## Факт и его подтверждение

Каждый элемент `golden_facts` — утверждение о текущем тексте источника из
`golden_sources`. Верность не выводится из наличия пути, даты или имени поля.

#### Scenario: факт подтверждён

- **WHEN** вопрос прошёл ревизию
- **THEN** у каждого его факта есть источник из `golden_sources`, дословный фрагмент,
  поддерживающий утверждение, и `as_of`, равный дате сверки

#### Scenario: фрагмента нет

- **WHEN** подтверждающий фрагмент не найден
- **THEN** факт переписан под текущий текст или удалён; в наборе не остаётся факта,
  помеченного как «вероятно верный»

#### Scenario: дата не равна чтению

- **WHEN** `as_of` обновлён без чтения источника
- **THEN** это нарушение контракта, а не свежесть: запись ревью обязана существовать раньше
  новой даты

## Графовые вопросы

#### Scenario: вопрос помечен `graph_required`

- **WHEN** `evidence_policy = graph_required`
- **THEN** `golden_graph_evidence = true` и у вопроса есть хотя бы один подтверждённый
  якорь; неподтверждённый якорь считается неизмеренным, а не отсутствующим дефектом

#### Scenario: графовый вопрос принят

- **WHEN** вопрос добавлен как проверяющий граф
- **THEN** его ответ опирается на путь через общую ноду, а вклад подтверждён
  `graph_only_chunks` на срезе v2; число `graph_required` и `necessity` приёмкой не являются
  (ADR-072)

## Распределение

#### Scenario: набор проходит ревизию распределения

- **WHEN** состав набора пересматривается
- **THEN** представлены все категории и все `reasoning_type` из словаря раннера, а число
  вопросов каждой страты следует правилу покрытия, а не заранее выбранному числу

#### Scenario: контроль отказа

- **WHEN** набор объявлен эталоном
- **THEN** контроль отказа (`answerability: unanswerable` и `partial`) проверяется отдельной
  стадией и не входит в эталонный файл: раннер считает `golden_sources` релевантными для
  любого вопроса, поэтому такая строка в общем наборе получила бы recall за документ,
  доказывающий отсутствие ответа. Разрыв назван явно, а не выдан за ноль

## Порог вывода по категории

#### Scenario: доля по категории

- **WHEN** в отчёте приводится вывод по категории
- **THEN** в категории не менее 3 вопросов; иначе она помечена «покрыто, не оценено», потому
  что одна строка не является результатом

## Значения, не входящие в эталон

#### Scenario: пилотное значение

- **WHEN** значение поддержано раннером, но не имеет определённой семантики (`alternatives`)
- **THEN** в `it` оно не добавляется, а записывается как пилотное; синоним существующего
  значения не заводится

#### Scenario: временной разрыв

- **WHEN** документ меняет действующее правило датой позже вопроса
- **THEN** в наборе есть вопрос `temporal-cross-document`, который требует упорядочить
  утверждения по датам; он входит в ядро редких типов

## Сокращение набора

#### Scenario: удаление вопроса

- **WHEN** вопрос удаляется или сливается с другим
- **THEN** причина — доказанная избыточность (совпадение фактов), а не желаемое число; после
  удаления ни одна категория не опускается ниже 3, а срез из 8 графовых вопросов не меняется
  без отдельного решения

## Знаменатель

#### Scenario: число названо

- **WHEN** в документе приводится доля или счётчик по набору
- **THEN** рядом указан знаменатель и его единица (вопросы или факты), потому что это разные
  величины и они уже давали разные числа
