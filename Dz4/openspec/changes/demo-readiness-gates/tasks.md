## Конвейер: путь «документ → граф» без ручной подготовки

- [ ] Убрать молчаливый переход в `vector_only` для пользовательского пути: отсутствие
      кандидатов объявляется поимённой причиной
- [ ] Обеспечить получение кандидатов до разбора для документа, загруженного из UI
- [ ] Сохранить различие «`CANDIDATES_DIR` не задан» (ошибка конфигурации) и «файла нет»
      (режим) — не сливать их в один отказ
- [ ] Проверить, что устаревший список кандидатов даёт отказ, а не предупреждение

## Гейт наполнения

- [ ] Прибор проверяет три условия независимо: `ContextNode` есть, связи есть, `failed` = 0
- [ ] Рядом с числом нод объявляется число загруженных документов
- [ ] Нулевой результат при ненулевом числе документов и нулевой результат при пустом корпусе
      называются разными результатами
- [ ] Гейт не проходит при пустом входе: «не измерено» и ненулевой код выхода, а не успех

## Гейт полного золотого набора

- [ ] Метрики публикуются со знаменателем: сколько вопросов из скольких оценено, какой срез
- [ ] Результат, посчитанный только на `golden_graph_evidence: true`, помечается как срез и
      не используется для объявления готовности
- [ ] Число вопросов с `golden_source` позже `as_of` объявляется числом
- [ ] Проверка повторяема: повторный запуск на том же наборе даёт тот же результат

## Сверка кандидатов

- [ ] `verify_candidates.py` включается в гайт готовности и падает на расхождении
- [ ] Проверить, что прибор и код считают `sha256` одной функцией (контракт свежести)

## Пользовательский путь UI

- [ ] Загрузка документа из UI даёт `ContextNode` и связи, а не только вектор
