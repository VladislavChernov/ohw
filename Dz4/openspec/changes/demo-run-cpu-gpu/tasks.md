|---|---|
| холодный старт `embeddings-service` | 68 с |
| тёплый старт, три свежих контейнера подряд | 6,0 / 6,2 / 6,2 с |
| `import sentence_transformers` | 66,4 с холодных, 5,2 с тёплых |
| `uv run --no-sync` | 0,1 с |
| импорт сервиса embeddings | 0,3 с |
| модель в VRAM (RTX 2070 SUPER, 8 ГБ) | ~5,35 ГБ при полной выгрузке |
| `driver: nvidia` в CPU-конфигурации | 0 вхождений (бронь снята) |
| `driver: nvidia` в GPU-конфигурации | есть для `llm` и `embeddings-service` |
| снятие брони через `devices: []` | не работает |
| снятие брони через `devices: null` | не работает |
