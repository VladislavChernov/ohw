# Delta Spec: demo-run-cpu-gpu

> Два способа поднять один и тот же демо-стенд: с видеокартой и без неё. Решение владельца
> от 2026-10-14. Требования новые; описание системы приведено в соответствие с кодом.

## ADDED Requirements

### Requirement: демо-стенд поднимается без видеокарты

Стенд должен подниматься на машине, где нет драйвера NVIDIA. Бронь видеокарты не должна
объявляться ни одним compose-файлом, который запускается в этом варианте: иначе Docker
не может удовлетворить запрос устройства и стенд не поднимается вообще.

Оговорка про силу: «не поднимается» здесь — полный отказ compose, а не ошибка одного
сервиса. Именно поэтому это требование, а не рекомендация.

#### Scenario: машина без NVIDIA

- **WHEN** запускается CPU-вариант на машине без драйвера NVIDIA
- **THEN** compose запускается без запроса устройства, все сервисы доходят до `healthy`,
  LLM считает на процессоре

#### Scenario: в CPU-варианте слои на GPU равны нулю

- **WHEN** CPU-вариант выставляет параметры окружения
- **THEN** `LLM_NGPU_LAYERS` равен `0`, а не значению по умолчанию

Ноль ставится явно: полагаться на то, что llama.cpp сам перейдёт на процессор, нельзя —
молчаливый выбор вычислителя выглядит как «тормозит», а не как «считает не там».

### Requirement: GPU выдаётся отдельным compose-файлом

Видеокарта выдаётся только явным оверлеем. Базовый compose не содержит брони устройства,
и оверлей не переписывает сервис целиком, а добавляет только бронь.

#### Scenario: GPU-вариант на машине с NVIDIA

- **WHEN** запускается GPU-вариант
- **THEN** compose подключает оверлей с бронью устройства, модель выгружается на GPU

#### Scenario: оверлей не может быть перекрыт

- **WHEN** проверяется, снимает ли оверлей броню через `devices: []` или `devices: null`
- **THEN** бронь остаётся, и это зафиксировано как факт

Требование существует, чтобы никто не «починил» это снова: проверено, что перекрытие не
работает, потому что бронь приходит через YAML-merge базового файла.

#### Scenario: у брони нет мёртвого якоря

- **WHEN** в базовом compose объявлен якорь брони видеокарты
- **THEN** ни один сервис этого файла на него не ссылается

Якорь без ссылок вводит в заблуждение: имя на месте, а броня не выдаётся.

### Requirement: имя параметра слоёв одно на все стенды

Параметр «сколько слоёв отдать видеокарте» обязан называться одинаково везде. Второе имя
означает, что переменная задаётся и молча не действует.

#### Scenario: расхождение имён

- **WHEN** в compose-файле, передающем `--n-gpu-layers`, встречается не `LLM_NGPU_LAYERS`
- **THEN** это признаётся расхождением, а не допустимым исключением

#### Scenario: значение по умолчанию

- **WHEN** переменная не задана
- **THEN** используется 99 — вся модель на GPU

### Requirement: бюджет здоровья не короче реального старта

`start_period` сервиса должен быть не короче его фактического старта, иначе compose
объявит контейнер больным и откажется ждать.

#### Scenario: холодный старт длиннее бюджета

- **WHEN** фактический старт сервиса больше `start_period + retries × interval`
- **THEN** `start_period` увеличен, иначе первый запуск на чистой машине падает

Закрывает пробел: правило было зафиксировано в `fill-ready-corpus` и применено к одному
файлу, а `compose.runtime.yaml` с 10 с остался непроверенным.

#### Scenario: тёплый старт

- **WHEN** контейнер уже лежит на диске и файлы образа прочитаны
- **THEN** старт укладывается в бюджет и стенд поднимается с первого раза

## Requirements: описание системы соответствует коду

### Requirement: устройство GPU описано как вариант, а не как факт

Описание системы обязано называть оба варианта запуска и говорить, чем они отличаются.

#### Scenario: чтение описания

- **WHEN** читается описание системы
- **THEN** в нём указано, что GPU нужен для GPU-варианта и не нужен для CPU-варианта

#### Scenario: описание расходится с фактом

- **WHEN** описание утверждает, что сервис считает на GPU
- **THEN** это проверяется по переменной его окружения

Описание эмбеддингов утверждало «bge-m3 (GPU)», тогда как `EMBEDDINGS_DEVICE` по
умолчанию равен `cpu`: расхождение существовало до этой правки и никем не сверялось.
