# Proposal: графовая ось обслуживает частично наполненный корпус

## Почему

Ось выключается целиком, если хотя бы один отслеживаемый документ не записан в граф
(`ProjectionReadiness.ready` требует `sources_without_graph == 0`). Измерено на наборе `ready`
2026-10-16: в журнале проекции 30 источников, в графе 17, `sources_without_graph = 13` →
`projection_status = sources_without_graph` на 12 из 12 вопросов, `graph_axis_active = false`,
`baseline recall@5 = target recall@5 = 0.6389`, `delta_recall = 0.0`, `verdict = invalid`.

Вывод «граф не нужен» из этих чисел не следует ничего: ось не работала ни на одном вопросе. Это
слепота прибора. При этом требование делает измерение невозможным на любом корпусе, кроме
загруженного целиком, а целиком он не будет никогда — новые документы приходят постоянно, и ADR-053
осознанно оставляет часть документов в векторе.

Основание уже принято в проекте: ADR-039 — «неразрешённые концы — обычное состояние частичной
загрузки, а не сбой». Правка ADR-046 (2026-10-16) и есть приведение гарда к этому принципу.

## Что делаем

- **Частичная проекция обслуживается.** Из условия готовности уходит ровно `sources_without_graph`;
  `revision_mismatches == 0` и `chunks_without_owner == 0` остаются жёсткими — это настоящая
  рассинхронизация, а не «документ ещё не загружен».
- **Слепота объявляется поимённо.** Каждый источник ответа несёт `graph_knowledge`:
  `contributed` (граф привёл), `reachable_unused` (узлы есть, обход не дошёл), `blind` (нод
  документа в графе нет) и причину для второго.
- **`necessity` показывается поимённо**, рядом со счётчиками слепых эталонов, иначе ноль на
  частично наполненном корпусе снова становится неоднозначным числом.

## Чего это не делает

Не подаёт текст достигнутых документов в промпт и не трогает `graph_boost`. Вклад графа
остаётся измеримым как **атрибуция** (каких документов коснулся обход), а не как обогащение
ответа текстом.

## Проверка

- Гард-тесты: `ready == true` ⇒ `revision_mismatches == 0 ∧ chunks_without_owner == 0`;
  `sources_without_graph > 0` больше не мешает `ready`; каждый источник несёт `graph_knowledge`.
- Гейт: `gate.sh full`.
- Прогон среза на демо-стенде: axis должна открыться, а результат сведён в сводный документ с
  метриками по каждому вопросу.
