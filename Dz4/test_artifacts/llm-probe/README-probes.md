# Первичные прогоны пробника извлечения

Четыре прогона, сделанные до того, как у серии появились критерии приёмки. Поэтому они
не самодостаточны: гипотезы, номера варианта и критерия в них нет. Ниже — что каждый из
них доказывает, чтобы артефакты не остались просто буквами.

| каталог | что показывает |
|---|---|
| `llm-probe-20260930-165440` | стенд работал на устаревшем образе: журнал честно пуст, 0 записей. Проверка самого пробника, а не модели. |
| `llm-probe-20260930-170953` | большой документ упал на таймауте embeddings при холодном старте, а не на LLM. Разделяет два разных отказа. |
| `llm-probe-20260930-172056` | пять вызовов, усечений нет (`truncated_any: 0`): токенов хватало и раньше. Сущности повторяются между секциями, связи приходят без `kind`. |
| `llm-probe-full-20260930-174640` | полный system + prompt + response для маленького документа. Единственная причина хранить: здесь видно, что массив `relationships` назван, а форма объекта внутри не задана. |

## Что из них использовано

- `172056` — основание утверждения «бюджет токенов не был причиной».
- `174640` — основание для генератора формы объекта связи (`prompt_renderer.py`).
- `170953` — основание для требования прогревать embeddings перед замером.
- `165440` — проверка пробника; артефакт ценен только как свидетельство, что пробник
  честно пишет ноль вместо правдоподобных данных.

## Чего в этих прогонах нет

Критериев приёмки и вердикта. По правилу, принятому после этого, прогон без заранее
записанного критерия артефактом не является; здесь они сохранены потому, что содержат
первичные данные, которые иначе получить нечем. Дальнейшие серии оформляются как
[эксперимент с формой и именами связей](./README.md).
