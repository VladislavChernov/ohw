B-Tree (RU)

B-дерево (B-tree) — сбалансированное дерево поиска, которое поддерживает
отсортированные данные и позволяет выполнять поиск, вставку, удаление и
последовательный доступ за логарифмическое время.

Ключевые свойства:
- все листья находятся на одной глубине;
- каждый узел хранит от t-1 до 2t-1 ключей;
- корень может иметь меньше ключей, чем t-1.

Пример на псевдокоде:

function search(node, key):
    i = 0
    while i < node.n and key > node.key[i]:
        i = i + 1
    if i < node.n and key == node.key[i]:
        return node
    if node.leaf:
        return NOT_FOUND
    return search(node.child[i], key)
