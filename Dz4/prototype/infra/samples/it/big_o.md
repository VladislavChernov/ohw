# Big-O нотация

Big-O нотация описывает рост сложности алгоритма при увеличении размера входа.

## Определение

Говорят, что функция f(n) = O(g(n)), если существуют такие константы c > 0 и n0,
что f(n) <= c * g(n) для всех n >= n0.

## Примеры

- O(1) — константная сложность
- O(log n) — логарифмическая
- O(n) — линейная
- O(n log n) — обычно сортировки
- O(n^2) — квадратичная

```python
def linear_search(arr, target):
    for x in arr:
        if x == target:
            return True
    return False
```
