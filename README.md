# 🧠 Учебная LLM (Language Model)

Это учебный проект, демонстрирующий принципы работы Трансформерной архитектуры на основе одного слоя самовнимания (`SelfAttention`). Проект реализует полный цикл машинного обучения языковой модели с нуля.

## 📚 Архитектура проекта и Конфигурация

Проект полностью параметризован через центральный файл **`config.py`**. Любое изменение гиперпараметра (количество эпох, размер батча, длина последовательности и т.д.) должно вноситься только в этот файл.

Основные компоненты:
*   **`data/story.txt`**: Единственный источник данных для обучения.
*   **`src/tokenizer/__init__.py`**: Токенизатор на уровне символов (`CharacterTokenizer`), который преобразует текст в индексы и обратно.
*   **`src/layers/__init__.py`**: Реализует базовый блок `SelfAttention`.
*   **`src/data/dataloader.py`**: Управляет пайплайном данных, создавая батчи в формате $\text{Input Sequence} \to \text{Target Token}$.
*   **`src/model/transformer.py`**: Определяет общую архитектуру LLM.
*   **`src/core/trainer.py`**: Реализует цикл обучения, используя `CrossEntropyLoss` и оптимизатор Adam на заданное число эпох, а также отвечает за **логирование результатов**.
*   **`src/core/utils.py`**: Утилиты для проверки среды и доступности GPU.
*   **`src/main.py`**: Главный оркестратор, который запускает весь рабочий процесс: проверка $\rightarrow$ обучение $\rightarrow$ генерация текста.

## 🚀 Запуск проекта (Workflow)

Проект рассчитан на работу в среде с поддержкой PyTorch и CUDA (NVIDIA).

### Предварительные требования
*   Python 3.8+
*   PyTorch с поддержкой CUDA (`torch` и `cuda`)
*   Библиотека `transformers`

### Шаги запуска
1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt # Предполагаемый файл зависимостей
   # Если нет requirements.txt, установите вручную:
   # pip install torch torchvision torchaudio transformers
   ```

2. **Запуск рабочего процесса (CLI):**
   Используйте аргументы командной строки для выбора режима.

   *   **Для обучения:** Запустит полную тренировку модели на `data/story.txt`.
       ```bash
       python src/main.py train
       ```
   *   **Для генерации (Инференс):** Запустите после успешного обучения, передав стартовый текст через аргумент `--prompt`.
       ```bash
       # Пример: сгенерировать текст, который начинается со слов "Вчера было солнечно"
       python src/main.py generate --prompt "Вчера было солнечно" 
       ```

### Что произойдет при запуске? (Последовательность действий)
1.  **Проверка среды**: Проверит доступность GPU и PyTorch.
2.  **Обучение**: Выполнит цикл обучения, выводя потери (`loss`) на каждой эпохе, и сохранит их в файл **`training_logs/training_loss.csv`**.
3.  **Генерация текста**: После успешного обучения автоматически перейдет к генерации текста, используя первые символы из обучающего файла как стартовый сид.
