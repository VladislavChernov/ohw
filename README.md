# ohw — Homework (OTUS)

Каждое домашнее задание — отдельная папка в корне репозитория:

| Задание | Описание | Статус |
|---|---|---|
| [dz1](dz1/) | Учебная LLM на одном слое самовнимания (SelfAttention) | реализовано |
| [dz2](dz2/) | CLI-утилита генерации тест-кейсов/чек-листов/тест-планов через ollama LLM | реализовано |
| [light-llm-engine](light-llm-engine/) | Движок запросов к локальной LLM (ollama): файл из `input/` → ответ модели → `output/`; запуск в Docker | реализовано |

Каждое задание имеет собственный стек и `.devcontainer/`. Открывайте нужную папку в VS Code как корневую (`Открыть папку → ohw/dzN`).

Общая инфраструктура — [`infra/`](infra/): единый сервис `ohw-ollama` с моделью
(volume `ohw_ollama_models`), который используют `dz2` и `light-llm-engine`.
Модель скачивается один раз и переиспользуется всеми проектами; запуск каждого
проекта поднимает только приложение. `dz1` — исключение: там свой CUDA-контейнер
для обучения/инференса без ollama. Подробности — в [`infra/README.md`](infra/README.md)
и README конкретного проекта.
