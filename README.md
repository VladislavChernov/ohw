# 🧠 Учебная LLM (Language Model)

Это учебный проект, демонстрирующий принципы работы Трансформерной архитектуры на основе одного слоя самовнимания (`SelfAttention`). Проект реализует полный цикл машинного обучения языковой модели с нуля.

## 📚 Архитектура проекта и Конфигурация

Проект полностью параметризован через центральный файл **`config.py`**. Любое изменение гиперпараметра (количество эпох, размер батча, длина последовательности и т.д.) должно вноситься только в этот файл.

Основные компоненты:
*   **`data/story.txt`**: Единственный источник данных для обучения.
*   **`src/tokenizer/__init__.py`**: Токенизатор на уровне символов (`CharacterTokenizer`).
*   **`src/layers/__init__.py`**: Реализует базовый блок `SelfAttention`.
*   **`src/data/dataloader.py`**: Управляет пайплайном данных, сканируя всю директорию `DATA_DIR` и конкатенируя все найденные TXT файлы в единый батчер.

## 🚀 Запуск проекта (Workflow)

Проект рассчитан на работу с командной строкой (CLI).

### Предварительные требования
*   Python 3.8+
*   PyTorch с поддержкой CUDA (`torch` и `cuda`)
*   Библиотека `transformers`

### Шаги запуска
1. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt # Предполагаемый файл зависимостей
   # Если нет requirements.txt, установите вручную:
   # pip install torch torchvision torchaudio transformers
   ```

2. **Запуск основного рабочего цикла (CLI):**
   Вы должны указать режим работы (`train` или `generate`) через аргументы командной строки.

   *   **Для ОБУЧЕНИЯ:** Запустите этот скрипт, чтобы создать модель и сохранить логи обучения.
       ```bash
       python src/main.py train
       ```
   *   **Для ГЕНЕРАЦИИ (Инференс):** Вы должны указать начальный запрос с помощью `--prompt`.
       ```bash
       # Пример: сгенерировать текст, который начинается со слов "Вчера было солнечно"
       python src/main.py generate --prompt "Вчера было солнечно" 
       ```

### Что произойдет при запуске? (Пошаговая логика)
1.  **Проверка среды**: Система сначала проверит GPU и зависимости, используя `src/core/utils.py`.
2.  **Обучение**: Вызывается `run_training()` из `src/main.py`, который использует `src/data/dataloader.py` для объединения данных и тренирует модель в `src/core/trainer.py`. Логи сохраняются в папку **`training_logs/`**.
3.  **Генерация текста**: Если был указан режим `generate`, система загружает обученную модель и выполняет инференс.
