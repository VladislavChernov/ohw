# 🧠 Учебная LLM (Language Model)

Это учебный проект, демонстрирующий принципы работы Трансформерной архитектуры на основе одного слоя самовнимания (`SelfAttention`). Проект реализует полный цикл машинного обучения языковой модели с нуля.

## 📚 Архитектура проекта и Конфигурация

Проект полностью параметризован через центральный файл **`config.py`**. Любое изменение гиперпараметра (количество эпох, размер батча, длина последовательности и т.д.) должно вноситься только в этот файл.

**Ключевые улучшения:**
1.  **Единый Источник Данных:** Система теперь не привязана к одному файлу. Она сканирует всю директорию `DATA_DIR` по расширениям `.txt`, `.pdf`, и `.docx`.
2.  **Паттерн Фабрики (Factory Pattern):** Логика загрузки данных вынесена в `src/data/dataloader.py`. Этот модуль использует **Dispatcher**, который вызывает соответствующий обработчик (`text_processor`, `pdf_processor`, `docx_processor`) на основе расширения файла, что делает систему высокорасширяемой.

### 📂 Структура модулей:
*   **`config.py`**: Хранит все константы и пути (включая `DATA_DIR`).
*   **`src/utils/*_processor.py`**: Содержат конкретную логику парсинга для каждого типа файла.
*   **`src/data/dataloader.py`**: Реализует Фабричный механизм, который сканирует все файлы и объединяет их в единый корпус текста.
*   **`src/main.py`**: Главный оркестратор, управляющий всем рабочим процессом: проверка $\to$ обучение $\to$ генерация текста.

## 🚀 Запуск проекта (Workflow)

Проект рассчитан на работу с CLI-аргументами.

### Шаги запуска
1. **Установка зависимостей:** (Необходимо для работы всех модулей).
   ```bash
   pip install -r requirements.txt # Предполагаемый файл зависимостей
   # Если нет requirements.txt, установите вручную:
   # pip install torch torchvision torchaudio transformers pypdf python-docx
   ```

2. **Запуск через CLI:**

   *   **Для ОБУЧЕНИЯ (Тренировочный режим):**
       ```bash
       python src/main.py train
       ```
   *   **Для Генерации (Инференс):** Требуется указать промпт:
       ```bash
       # Пример: сгенерировать текст, который начинается со слов "Вчера было солнечно"
       python src/main.py generate --prompt "Вчера было солнечно" 
       ```

### Что произойдет при запуске? (Пошаговая логика)
1.  **Проверка среды**: Система проверяет GPU и зависимости.
2.  **Обучение**: Сканирует всю папку `data/` по всем поддерживаемым расширениям, вызывает правильный обработчик для каждого файла и конкатенирует их содержимое в один корпус данных. Затем запускается цикл обучения с этим корпусом.
3.  **Генерация текста**: Использует обученную модель и заданный промпт.
