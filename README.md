# ohw — Homework (OTUS)

Учебный монорепозиторий курса OTUS. Каждое домашнее задание — отдельная папка
в корне репозитория; общие сервисы и внутренние инструменты — в `infra/`.

## Домашние задания

| Задание | Описание | Статус |
|---|---|---|
| [dz1](dz1/) | Учебная LLM на одном слое самовнимания (SelfAttention) | реализовано |
| [dz2](dz2/) | CLI-утилита генерации тест-кейсов/чек-листов/тест-планов через ollama LLM | реализовано |
| [dz3](dz3/) | Генератор API-автотестов через LLM: простой (pytest-код) + продвинутый (свой движок) | spec готов |
| [light-llm-engine](light-llm-engine/) | Движок запросов к локальной LLM (ollama): файл из `input/` → ответ модели → `output/`; запуск в Docker | реализовано |

Каждое задание имеет собственный стек и `.devcontainer/`. Открывайте нужную
папку в VS Code как корневую (`Открыть папку → ohw/dzN`).

## Инфраструктура монорепо

Общие сервисы и внутренние инструменты, переиспользуемые между проектами.
Новые такие инструменты добавляются в таблицу ниже.

| Компонент | Назначение | Кто использует | Статус |
|---|---|---|---|
| [infra/](infra/) | Единый LLM-сервис `ohw-ollama` (модель `qwen2.5:7b-instruct`, volume `ohw_ollama_models`): скачивается один раз и переиспользуется проектами; запуск каждого проекта поднимает только приложение | dz2, dz3, light-llm-engine | реализовано |

`dz1` — исключение: там свой CUDA-контейнер для обучения/инференса без ollama.
Подробности — в [`infra/README.md`](infra/README.md) и README конкретного проекта.
